# Slackbot - Karoltoo11
Working on the bot was a very pleasant experience. I hadn't had any prior exposure to this programming language, but generally speaking, I think bots built with it tend to be more optimized or simply easier to write and requiring fewer lines of code.

## Commands
The bot contains several commands which are listed below:
- `/karoltoo11bot-status` - Chceck if the bot is working.
- `/karoltoo11bot-commands` - Displays all commands.
- `/karoltoo11bot-kittyfact` - Give a fact about cats. // API: https://catfact.ninja/fact
- `/karoltoo11bot-doggyfact` - Give a fact about dogs. // API: https://dogapi.dog/api/v2/facts
- `/karoltoo11bot-funfact` - Give a tottaly random fact. // API: https://uselessfacts.jsph.pl/api/v2/facts/random
- `/karoltoo11bot-daddyjokes` - Give a very funny daddy joke. // API: https://api.chucknorris.io/jokes/random

## Where is the bot hosted?
The bot is hosted on the Hack Club Nest server and is managed by the systemd process.

## Translation
Since English is not my native language, everything was translated using Google Translate.
